Open Harness 2

Own one agent on a host you control — the same course, rebuilt for reading.

Thirteen lessons across two parts, plus quick wins you can run today. Progress is shared with the original edition: tick a box here, it is ticked there.

Start lesson 00 ↗

Part I — Working assistant

Words → install → personality → messaging of your choice → first real action on disk.

  1. 00Welcome — Open HarnessWhat you will be able to do, how the course is ordered, and how to work through each lesson.5 min
  2. 01LexiconWords you will meet often. First pass = the short “remember” lines; details wait for later lessons.25 min
  3. 02Your machine + DesktopBaseline: dedicated hardware. Then Delta V SOTA prefs (Nous + VPS, open weights, Swiss host, Venice). Exceptions only if you must.10 min
  4. 03Install Hermes DesktopInstall on the host you chose in 02. Connect a free model route if you accept cloud data leaving the box.30 min
  5. 04Soul packWrite identity into Hermes home. Keep project rules in project context files.25 min
  6. 05Gateway (your pocket surface)Chat with your agent from an app you already use. We recommend Telegram; you may use Discord, Slack, Signal, WhatsApp, or another Hermes-supported platform.25 min
  7. 06First agencyFeel Think → Act → Observe on a real task: tools touch disk, you approve risk, a file receipt opens offline.40 min

Part II — Memory and routines

Remember facts, use your notes, set safety rules, run one scheduled job, know what to back up.

  1. 07Memory floorsContext is session RAM. Durable memory is on disk. Caps are intentional.30 min
  2. 08Data vaultA markdown vault as the library floor — notes you keep and the agent can retrieve.25 min
  3. 09SkillsOn-demand procedural memory — how skills relate to tools, the agent loop, and fixed session cost.22 min
  4. 10Security dialsHost isolation, cloud data leaving the box, who may reach tools, and how approvals work.22 min
  5. 11Cron runbooksScheduled work as a full runbook. Each fire starts without prior session memory.25 min
  6. 12Own it foreverBackup, update habit, and growth map — without expanding the day-one path.20 min
