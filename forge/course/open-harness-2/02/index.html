Your machine + Desktop

Baseline: dedicated hardware. Then Delta V SOTA prefs (Nous + VPS, open weights, Swiss host, Venice). Exceptions only if you must.

Baseline: dedicated hardware

This course assumes you install Hermes on a machine that exists for the agent — a spare PC, mini-PC, old laptop wiped for this purpose, or similar. Not the computer that holds banking, work SSO, password vaults, and family photos.

Why: once tools are on, the agent can act like a capable operator with a shell on that OS. Treat the host as something you can wipe and rebuild without wrecking daily life.

  • ·Windows, macOS, or Linux Desktop as offered for your build
  • ·Hermes home is a folder on that host — you back up by copying folders
  • ·Next lesson (03) installs Desktop on this box

Where the brain runs (day one)

Hermes on your dedicated box is the cockpit. Day-one free routes (OpenRouter ↗, OpenCode ↗) usually run elsewhere. Your prompts, replies, and often tool context leave the host. Useful for learning — not private. Accounts are created at install (03).

  • ·Do not paste secrets, customer data, or keys into cloud chats “just to try”
  • ·Local / open weights later = different trade-off (see SOTA prefs below)

Delta V SOTA preferences

Editorial stack we actually like for serious use — not required on day one. Free OpenRouter/OpenCode still fine for first chat. When you pick a paid, private, or production shape, start here.

  • ·Favourite combo: Nous ↗ subscription (Portal) for models/tools + agent on a VPS (we like Infomaniak ↗ when you want Swiss jurisdiction)
  • ·Open path: pull open models via Hugging Face ↗ (and run them on dedicated HW / your infra when you can)
  • ·Anon / uncensored cloud path: look at Venice.ai ↗ as a provider option in Hermes when that fits your policy
  • ·Isolation path: Docker per Hermes docs if the box is not lab-only
PreferenceRoleWhy we point here
Nous Research (Portal) + VPSSubscription models/tools + agent on a serverOfficial Hermes lineage; clean combo: managed brain/tools, process on a host you control
Hugging Face / open weightsOpen models, hubs, local or self-host inferenceBig open-source ecosystem — prefer open weights when you can run them on dedicated HW or a GPU box
Infomaniak (Switzerland)VPS / cloud hostSwiss privacy law jurisdiction for the runtime when you rent a box instead of a spare PC
Venice.aiPrivacy-oriented / less-censored cloud modelsWhen you want anonymous-leaning or uncensored inference without defaulting to big closed chat apps
Docker (Hermes backends)Isolate tool/shell from the host OSIf you must share a personal machine: official Hermes Docker / terminal-backend path — not bare host shell
These are preferences, not exclusive contracts. Labels and pricing move — official provider and Hermes docs win. Contact Delta V if you want a tailored multi-host layout.

Exceptions (only if no dedicated hardware)

Baseline is still a spare box. If you truly cannot dedicate hardware:

ExceptionDo thisDo not
VPS (prefer Swiss when privacy matters)Run the agent on a small always-on server (Infomaniak is our default pointer); daily laptop is client onlyLeave SSH open to the world or dump personal secrets onto the VPS
Personal PC + DockerFollow Hermes Docker / terminal backends so tools do not own your host userBare host shell next to banking browser and password vault
No spare box yet? Pause install, rent a small VPS (or wipe an old machine), then continue. Do not “just try it” bare on the daily laptop.
