Data vault

A markdown vault as the library floor — notes you keep and the agent can retrieve.

Vault = a folder

An Obsidian ↗ vault is a folder of markdown on disk. Local use needs no account. Once connected, the agent can read and write there. This is floor three from the memory module: unlimited library, still files you own — the file over app ↗ idea.

Steps · tap the number to check0/5
  1. Install Obsidian. Create a vault (for example second-brain).
  2. Create three folders: inbox / sources / synthesis.
  3. Add two or three short notes about a real project.
  4. Connect Hermes to the vault path (Obsidian skill / config for your version).
  5. Ask: “Find my notes on X and summarize with quotes.”

Wiki pattern (later)

Pure retrieval re-searches every time and compounds little. A wiki-style loop deposits sources, summarizes, updates linked pages, and flags contradictions. The vault becomes compiled knowledge.

Course default: files on disk plus vault. External memory providers remain optional and never replace your files.
