Welcome — Open Harness

What you will be able to do, how the course is ordered, and how to work through each lesson.

5 min

Clear outputs

This course teaches you to run a personal AI assistant you control (Hermes Desktop), with optional free cloud models. Prefer a dedicated machine (spare PC or VPS) — not the computer that holds your daily life. Below is what you can do after each part — not slogans.

WhenYou can
After Part IInstall Hermes on a host you chose on purpose; chat with a free model; set how the assistant behaves; message it from an app you choose; leave a file on disk that proves it acted.
After Part IIKeep facts that survive next week; use a notes folder; set clear yes/no rules for risk; run one scheduled checklist job; know which folders to copy for backup.

Course structure

Thirteen lessons in two parts. Finish Part I before Part II. Part II expects: Desktop chat works, a personality file is set, and one messaging surface is trusted.

  • ·00 welcome · 01 lexicon (incl. agent loop) · 02 machine · 03 install · 04 personality · 05 messaging · 06 first action
  • ·07 memory · 08 notes folder · 09 skills · 10 safety rules · 11 scheduled job · 12 keep it
PartLessonsFocus
I00–06Words (stack + Think→Act→Observe + messages) → host + install → personality → pocket messaging → first real action
II07–12Memory → notes → skills → safety rules → scheduled job → backup
Optional labs exist after Part I for drills. They are not required to finish the main path.

What this course is (and is not)

Day one is Hermes Desktop on a host you chose for the agent. Free model accounts (OpenRouter and/or OpenCode) are set up at install if you use cloud brains. We teach vocabulary before install so Settings screens make sense — and we tell you honestly what leaves your machine.

  • ·Is: a free path to own one agent — plus plain-language agent fundamentals (loop, messages, tools)
  • ·Is: proofs on disk (files, settings, backups), not only chat cleverness
  • ·Is not: a green light to run a tool-using agent on the same laptop as banking, work SSO, and family photos
  • ·Is not: a Python coding bootcamp or a framework comparison course (we stay on Hermes)
  • ·Is not: a guarantee of income, AGI, or a set-and-forget public bot
  • ·Cloud models: conversation content (and tool context) is sent to the model host — treat it as leaving your machine
  • ·UI labels follow official Hermes docs and may change; docs win when labels move

How to follow

  • ·Do lessons in order. Each ends with a short “you are done when” check.
  • ·Do not skip 01 unless you can already explain agent vs chat, harness vs runtime, and Think → Act → Observe.
  • ·Pick your host in lesson 02 before install (dedicated machine preferred).
  • ·Next: lesson 01 — lexicon (stack, loop, messages, then the rest).
