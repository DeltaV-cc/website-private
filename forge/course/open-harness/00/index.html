Welcome

What you will be able to do, how the course is ordered, and how to work through each lesson.

Clear outputs

This course teaches you to run a personal AI assistant you control (Hermes Desktop ↗), with optional free cloud models. Prefer a dedicated machine (spare PC or VPS) — not the computer that holds your daily life. Below is what you can do after each part.

WhenYou can
After Part IHave your Hermes agent installed and running on a free model, give it the personality you want, message it from your phone, and have it ready to work with you — with a file on disk that proves it acted.
After Part IIPut it to work. Automate the tasks you repeat, on a schedule. Scrub your name off data-broker sites. Hand it a book, a codebase or a docs site and have it learn the subject in depth. Give it a memory that survives next week, rules about what it may do unattended, and a backup you can carry to another machine — then keep adding jobs for as long as you keep finding them.

What this course is (and is not)

Day one is Hermes Desktop on a host you chose for the agent. Free model accounts (OpenRouter ↗ and/or OpenCode ↗) are set up at install if you use cloud brains. We teach vocabulary before install so Settings screens make sense — and we tell you honestly what leaves your machine.

  • ·Is: a free path to own one agent — plus plain-language agent fundamentals (loop, messages, tools)
  • ·Is: proofs on disk (files, settings, backups), not only chat cleverness
  • ·Is not: a green light to run a tool-using agent on the same laptop as banking, work SSO, and family photos
  • ·Is not: a Python coding bootcamp or a framework comparison course (we stay on Hermes)
  • ·Is not: a guarantee of income, AGI, or a set-and-forget public bot
  • ·Cloud models: conversation content (and tool context) is sent to the model host — treat it as leaving your machine
  • ·UI labels follow official Hermes docs ↗ and may change; docs win when labels move

How to follow

  • ·Do lessons in order. Each ends with a short “you are done when” check.
  • ·Do not skip 01 unless you can already explain agent vs chat, harness vs runtime, and Think → Act → Observe (the printable glossary helps).
  • ·Pick your host in lesson 02 before install (dedicated machine preferred).
  • ·Optional labs exist after Part I for extra drills — not required to finish the main path.
  • ·Next: lesson 01 — lexicon (stack, loop, messages, then the rest).
