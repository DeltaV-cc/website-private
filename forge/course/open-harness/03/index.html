Part I · Sovereign agent · 03

Install Hermes Desktop

Download Desktop, finish setup, chat once. Advanced settings can wait.

25 min

You need

  • ·A PC you control (Windows or macOS — Linux Desktop if offered for your build)
  • ·Network access for download + one model provider

Install Desktop

Every later module assumes this cockpit: chat, profiles, tools, approvals, gateway, cron.

  1. 01Open hermes-agent.nousresearch.com and download Hermes Desktop for your OS.
  2. 02Install and launch the app.
  3. 03Run the setup wizard. One reliable provider first. Optional: Portal / “setup with portal” if the app offers it (model + Tool Gateway in one go).
  4. 04Stop when chat works — do not configure Telegram yet. Do not open Settings → Advanced yet.
  5. 05Send: “Reply with one sentence confirming you are online.”
  6. 06Optional: open health / doctor in the app if shown; fix only what blocks chat.
Day-one path is Desktop on this PC (as of 2026-08-06). If a wizard label moved, official Installation docs win.

  • Installation docs ↗
  • Quickstart ↗

Peek: Settings you will meet later

After chat works, open Settings once just to know the map — then close without changing Advanced defaults.

  • ·Providers / models — cloud APIs, local endpoints, routing (where the brain lives)
  • ·Gateway / messaging — Telegram and other surfaces (module 05)
  • ·Advanced — terminal backend, Docker, isolation (do not enable for Part I proofs)
CLI install, Termux, and bare VPS installs are valid Hermes paths in official docs. This course stays on Desktop so newbies are not juggling shells on day one.
  • All install methods ↗
  • Docker guide ↗

Stabilize one provider

Pick one model provider you can call reliably, then stop. Do not debug gateway, Docker, and auth at the same time.

Where your files live

Desktop still stores the harness on disk (Hermes home — often ~/.hermes or under your user AppData). Profiles isolate homes: each profile is a sealed house. You back up by copying folders — same files if you later run that home on a VPS.
